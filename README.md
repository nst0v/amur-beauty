# АМУР — студия красоты во Владимире

Мобильный демонстрационный сайт для согласования с салоном. Статический HTML, CSS и JavaScript: без сервера, базы данных и обязательных платных сервисов.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Адрес после включения Pages: https://nst0v.github.io/amur-beauty/

Фотографии в `assets/` — из публикаций сообщества, а не из фотостоков. Для каждой фотографии сохранены происхождение и размеры в `assets/sources.json`. Подборки трендов и чужие референсы не используются как портфолио студии.

Демо не принимает и не хранит персональные данные: запись выполняется на официальной странице DIKIDI, в сообщениях ВКонтакте или по телефону. Свободные окна не имитируются.
