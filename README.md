# АМУР — сайт салона красоты во Владимире

Демо: https://nst0v.github.io/amur-beauty/

Статический HTML/CSS/JavaScript, GitHub Pages. Каталог и выбор услуги/мастера находятся на сайте; живой календарь и подтверждение подключены через встроенную форму действующей системы записи салона.

## Что реализовано

- Все 44 услуги и 7 мастеров из открытого каталога салона на 9 сентября 2026 года.
- Проверены 87 связей «услуга — мастер»: цена и длительность каждого исполнителя, а не приблизительный подбор по специализации.
- Поиск по названию услуги и имени мастера, категории каталога, карточки всех специалистов. Шесть исходных портретов сохранены локально; у Ирины вместо отсутствующего фото показан инициал.
- Три шага: услуга → мастер → дата и время. Выбор подсвечивается и подтверждается отдельной кнопкой, сохраняется при переходе назад. Можно начать с конкретной услуги или специалиста.
- Реальный календарь встроен в сайт и получает оба выбранных идентификатора. Нет выдуманных слотов или имитации успешной записи.
- Галерея работ, отзывы Яндекса, контакты, мобильная панель записи. Плашки часов и рейтинга не перекрывают фотографию первого экрана.

## Основные файлы

`index.html` — готовая статическая страница. `styles.css` — основной дизайн. `app.js` — меню и галерея. `booking.js` и `booking-flow.css` — новая форма записи и поиск каталога. `data/catalog.json` — проверенный снимок всех услуг, мастеров и индивидуальных предложений. `assets/team/` — портреты.

`python3 -m http.server 8080` запускает локальный просмотр. Для загрузки JSON нужен HTTP, а не открытие HTML через file://.

## Данные и их обновление

Каталог — снимок на дату `fetchedAt`, а не онлайн-синхронизация при каждом визите. Само расписание всегда загружает действующая форма записи. Источники сохранены в JSON и `CONTENT-SOURCES.md`.

Обновление по запросу владельца, без изменения расписания:

```bash
python3 -m pip install beautifulsoup4 Pillow
python3 scripts/export-booking-catalog.py
python3 scripts/enrich-booking-catalog.py
python3 scripts/build-booking-page.py
```

Проверить изменения, выполнить тесты и закоммитить данные/изображения/HTML. Одноимённые услуги не объединять: разные ID могут иметь разных исполнителей и длительность. Архивные брови/педикюр из старого прайса не добавлять в запись без подтверждения действующего предложения.

## Запись и ограничения

Используется поддерживаемая форма для конкретного мастера и услуги: `st_m=1`, `sm_m=<master ID>`, `ss_s=<service ID>`, `mode=website`. Окно выбора времени остаётся внутри страницы. Это не собственный сервер расписания и не неофициальный прокси. Сообщения iframe проверяются по origin, source и modalId. При недоступности формы предусмотрены обновление и явная резервная ссылка с сохранением выбора.

Сайт не сохраняет имя/телефон клиента. Во встроенной форме данные и cookies обрабатываются её поставщиком. Дизайн календаря и его системные уведомления принадлежат поставщику. Изменение его темы потребует доступных настроек салона. Посетитель должен самостоятельно завершить подтверждение записи.

## Проверки и публикация

`tests/booking_smoke.py` проверяет 320, 360, 390, 430, 768, 1024, 1440 px: полный каталог, совместимость, цены, выбранные состояния, возврат к шагам и фокус. Отдельная сетевая проверка загружает настоящий календарь выбранного мастера/услуги. `tests/booking_webkit.py` проверяет мобильное поведение WebKit. `tests/browser_check.py` проверяет остальную страницу; проверка hero сохранена в `scripts/fix-mobile-hero-note.py --verify`.

```bash
python3 -m pip install playwright
python3 -m playwright install --with-deps chromium webkit
python3 tests/booking_smoke.py
python3 tests/booking_webkit.py
python3 tests/browser_check.py
```

Тесты не создают записей, не занимают время и не отправляют SMS. Проверка настоящего календаря блокирует запросы резервирования/подтверждения. Артефакты Actions содержат отчёты и скриншоты; фактический результат — в конкретном запуске.

Публикация Pages настроена из `main`, корень. Демо сохраняет `noindex, nofollow`. Перед коммерческим запуском согласовать материалы и права на изображения с салоном, проверить запись владельцем и снять запрет индексации. Файлы шрифтов в репозиторий не включены.
