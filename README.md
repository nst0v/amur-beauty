# АМУР — студия красоты во Владимире

Мобильный демонстрационный сайт для согласования с салоном. Статический HTML, CSS и JavaScript: без сборщика, сервера, базы данных и обязательных платных сервисов.

## Посмотреть сайт

Адрес GitHub Pages после включения публикации: **https://nst0v.github.io/amur-beauty/**

В репозитории: **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Публикация из корня поддерживается файлом `.nojekyll`. Последующие коммиты обновляют сайт, когда Pages включён.

## Что реализовано

Адаптивная вёрстка, мобильная панель записи, категории прайса, дополнительные раскрывающиеся услуги, фильтруемая галерея восьми работ, увеличение фотографий со стрелками и свайпом, карточки актуальных мастеров, два реальных фрагмента отзывов, FAQ и контакты с маршрутом. Запись — через DIKIDI, ВКонтакте или телефон. Доступны клавиатурная навигация, Escape, возврат фокуса и reduced-motion. Галерея хранится локально в WebP. Ни фальшивых свободных окон, ни имитации отправки заявок нет.

## Файлы

- `index.html` — контент, цены, контакты и разметка.
- `styles.css` — дизайн и адаптивность.
- `app.js` — вкладки, галерея, меню и окна записи.
- `assets/` — изображения и происхождение каждого снимка в `sources.json`.
- `CONTENT-SOURCES.md` — источники и расхождения, которые нужно согласовать.
- `tests/browser_check.py` — браузерные проверки и сборка переносимой копии.

Для локального просмотра достаточно открыть `index.html`. Для проверки через HTTP: `python3 -m http.server 8080`.

## Проверки

Workflow **Verify Amur website** проверяет 320, 360, 390, 430, 768, 1024 и 1440 px: отсутствие горизонтальной прокрутки, работу прайса и клавиатуры, запись без отправки данных, изображения, фильтры, лайтбокс, мобильное меню и fallback без JavaScript. В Actions → артефакт `amur-website-preview` находятся отчёт, скриншоты и ZIP сайта. Фактический результат проверок — в конкретном запуске Actions, а не в этом описании.
